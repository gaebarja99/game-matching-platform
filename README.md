# GameMatcher

게임 매칭, 라이브 방송, 채팅, 후원, 커뮤니티, 관리자 센터 기능을 포함한 프로젝트입니다.

개발 기본 주소
- 프론트: `http://127.0.0.1:5173`
- 백엔드: `http://localhost:8080`

## 2026-03-26 작업 정리

이번 작업에서는 메인 ZIP 기준 병합 후 깨진 기능들을 다시 연결하고, 프론트/백엔드 동선을 실제 사용 가능한 상태로 정리했습니다.

주요 반영 내용
- 관리자 센터 화면을 `feature/ju-000` 기준 구조와 스타일에 맞춰 복구
- 스튜디오의 `방송하기`, `설정`, `팬`, `채널 관리`, `권한 관리` 화면 반영
- 스튜디오 좌측 사이드바를 요청한 메뉴 구조에 맞게 재정리
- 카테고리 페이지 추가 및 카드 구성 조정
- 프로필 좌측 사이드바를 요청한 구조로 재구성
- 팡/마일리지 상점 문구와 표시 형식 수정
- 팡 내역에서 이벤트 지급 건 표시 방식 수정
- 관리자 이벤트 팡 지급 알림 메시지 저장/표시 처리
- 포트원 결제 설정 연결
- Firebase 전화 인증 로컬 폴백 추가
- 랭킹 유저 클릭 시 해당 스트리머 채널로 이동하도록 연결
- 채널 페이지를 내 채널/타인 채널 공용 구조로 정리
- 라이브 시청 페이지에서 채팅 툴바 정리
  - `후원하기`, `귓속말`, `채팅창 지우기`만 유지
  - 귓속말 대상 선택 모달 추가
  - 채팅창 지우기 버튼 추가
- 라이브 채팅 주간 후원 총합 숫자 표시 제거
- 욕설 메시지는 차단하지 않고 `**`로 마스킹되도록 변경
- 욕설 필터 누적 10회마다 채팅 금지 시간이 1분씩 증가하도록 서버 적용
  - 그룹채팅
  - 랜덤 매칭 채팅
  - 귓속말
  - 라이브 채팅
- 방송 등록 시 `live_streams` 스키마 불일치로 나던 오류 대응
  - `chat_scope`
  - `warning_count`
  - 관리자 경고/채팅 관련 컬럼 매핑 보강
- RTMP/FFmpeg 경로를 로컬 경로에 맞게 연결

## 현재 로컬 설정 메모

### FFmpeg
로컬 FFmpeg 경로는 아래 기준으로 연결되어 있습니다.

```text
D:\T4 GameMatcher\ffmpeg-2026-03-05-git-74cfcd1c69-full_build\bin\ffmpeg.exe
```

RTMP 서버를 재시작해야 최신 경로가 반영됩니다.

### PortOne
로컬 결제 설정 파일:

```text
src/main/resources/application-portone-local.properties
```

현재 로컬 테스트용 포트원 설정이 반영되어 있습니다.

### Firebase
로컬에서는 Firebase 전화 인증이 실패할 경우 개발용 폴백 코드를 사용합니다.

기본 개발 코드

```text
123456
```

## 실행 방법

### 1. 백엔드 실행

```bash
mvn spring-boot:run
```

### 2. 프론트 실행

```bash
cd frontend
npm install
npm run dev
```

### 3. RTMP 서버 실행

```bash
cd rtmp-server
npm install
npm start
```

기본 RTMP 주소

```text
rtmp://localhost:1935/live
```
